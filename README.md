# Thala 7 Sneaker Store

Thala 7 Sneaker Store is a simple sneaker shopping website made using **HTML and CSS**.

This project is created for practicing basic web development concepts like HTML pages, navigation, images, buttons, and simple website layout.

## Features

* Home page
* Products page
* Shopping cart page
* Payment page
* Navigation bar
* Product image
* Product price and details
* Quantity input
* Add to Cart button
* Proceed to Payment button
* Simple and beginner-friendly design

## Technologies Used

* HTML
* CSS

## Project Structure

Thala-7-Sneaker-Store/

├── index.html

## Pages

### Home Page

The home page contains:

* Website logo
* Navigation menu
* Hero section
* Shoe image
* Shop Now button
* Customer reviews
* Customer count
* Quality information
* Rating

### Products Page

The products page shows:

* Shoe image
* Shoe name
* Price
* Product description
* Quantity input
* Add to Cart button

### Cart Page

The cart page shows:

* Selected shoe
* Price
* Quantity
* Total price
* Proceed to Payment button

### Payment Page

The payment page is used as the next step after the cart page.

## How to Run

1. Download or clone this project.
2. Open the project folder.
3. Make sure the `images` folder contains `shoe1.jpg`.
4. Open `index.html` in a browser.
5. You can navigate between the pages using the navbar.
